🌸 Installer la communauté des mams

Page réservée à Mélanie. Elle sert à copier le code à coller dans Supabase.
Étape 1 : la base de données
  1. Touche le bouton ci-dessous pour copier le code.
  2. Dans Supabase, ouvre SQL Editor, puis New query.
  3. Colle le code (appui long dans la zone, puis « Coller »).
  4. Touche Run. Le message « Success » doit s'afficher.
Étape 2 (après ton inscription dans Mams) : devenir administratrice
  1. Copie ce petit code.
  2. Dans Supabase, SQL Editor → New query → colle.
  3. Remplace TON_EMAIL par l'adresse e-mail de ton compte Mams, puis Run.
